Atlas Repository

Kodi addon repository for Lions (plugin.video.lions)

Install in Kodi

Method 1 — Install repo zip directly:

https://rhoulou.github.io/atlas/repo/zips/repository.atlas/repository.atlas-1.0.0.zip

Kodi → Settings → Add-ons → Install from zip → paste URL above

Method 2 — Add as Repository source (requires File Manager):

GitHub Pages doesn't list directories, so instead use the raw zip URL above.
