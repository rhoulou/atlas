Atlas Repository

Kodi addon repository for Lions (plugin.video.lions)

Install in Kodi

  1. Settings → System → Add-ons → Enable Unknown Sources
  2. Settings → Add-ons → Install from zip
  3. Enter this URL:
    https://rhoulou.github.io/atlas/repo/zips/repository.atlas/repository.atlas-1.0.0.zip
  4. Go to Install from repository → Atlas Repository → Lions → Install
